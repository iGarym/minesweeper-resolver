# minesweeper-resolver

一个 **扫雷解题 Web 页**（原生 TypeScript）。你手动回填“已揭示数字/标雷”，然后点击“求解（只高亮）”，页面会把当前条件下能推出的 **必开** / **必雷** 格子高亮出来（不会自动修改棋盘）。

## 运行

```bash
npm i
npm run dev
```

打开终端提示的本地地址。

## 使用

- **生成棋盘**：输入行/列后点击“生成棋盘”
- **选中格子**：点击任意格子
- **PC 键盘录入**
  - `0~8`：把选中格设为“已揭示数字”
  - `F`：切换标旗
  - `U` / `Backspace` / `Delete`：设为未知
  - `Esc`：取消选中
- **移动端录入**
  - 选中格子后，底部会出现数字键盘（0~8 / 标旗 / 未知 / 取消）
- **求解（只高亮）**
  - 绿色边框：必开
  - 红色边框：必雷

## 说明

目前求解器仅实现 **确定性推理**（基础约束规则 + 子集推理），不会做概率/猜测。
